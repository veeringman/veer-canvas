# Logo

- `lockup.svg` / `lockup.png` — raven mark plus wordmark, for light surfaces.
- `lockup-on-dark.svg` / `lockup-on-dark.png` — same lockup for night surfaces.
- `mark.svg` — the raven alone.
- `app-icon.svg` — vector app icon.
- `raven-app-icon.png` — rendered 1024 icon.
- `icon-512.png`, `icon-192.png`, `favicon-32.png` — resized from the rendered icon.
- `favicon.svg` — same drawing as the vector app icon.

Wordmark outlines are Outfit (SIL Open Font License). See `brand/fonts/OFL.txt`.

Usage rules are in `docs/BRAND.md`.
