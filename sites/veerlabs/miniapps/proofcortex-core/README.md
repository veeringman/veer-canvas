# ProofCortex-Core 🔒

Private repository for the **ProofCortex Runtime & Proof Engine**.

### Overview
This repository houses the **core deterministic runtime**, **ZK/cryptographic proof modules**, and **model integrity framework**.  
It serves as the production-grade backend for the VeriCortex project, interfacing with the public `vericortex-blockdag-demo` repo through API and crate bindings.

### Key Components
- `runtime/`: WASM warm pool manager, sandbox engine
- `proofs/`: Proof generator and verifier circuits
- `model_registry/`: Model metadata integrity and checks
- `integrations/`: BlockDAG and external API connectors
- `tests/`: Internal stress, security, and integration tests

🚫 **Confidential:** Do not distribute or expose this repository publicly.
